## Project Overview
This project demonstrates a cloud-based Sentiment Analysis Dashboard using Microsoft Azure.

## Azure Services Used
- Azure AI Language (Text Analytics)
- Azure Cosmos DB
- Power BI Desktop

## Architecture Flow
Guest → Web Interface → Azure AI Language → Cosmos DB → Power BI

## Features
- Real-time sentiment classification
- Storage of review data
- Interactive Power BI dashboard
